# Inter 2024

This part of the exam contains the following parts:

## Adagrad (2 points)

This class is contained in the src.optimization. You will have to complete the constructor and step method. It is not allowed to use methods such as add or sub, only +, -, * and /.

## PReLU forward (0.75 points)

This function is contained in the src.models. You will have to implement the forward method without using the nn package.

## PReLU backward (0.75 points)

This function is contained in the src.models. You will have to implement the backward method without using the nn package.

## Residual forward (0.75 points)

This method is contained in the src.models. You will have to implement the forward method without using the nn package. It is recommended to call the PReLU forward to reuse the function you already coded.

## Residual backward (0.75 points)

This method is contained in the src.models. You will have to implement the backward method without using the nn package. It is recommended to call the PReLU backward to reuse the function you already coded.
