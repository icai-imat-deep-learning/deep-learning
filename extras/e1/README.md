# Extra 1

This is the first extra for the course. The value of it will be a 0.5 points increase over the final grade of the course. The deadline is the same as for the first project, but for this, no slip day will be allowed. 

## Description
For this extra, you will have to read and implement the Saliency Map paper ([link](https://arxiv.org/abs/1312.6034)). In the paper two techniques are presented, the Saliency Map and the Occlusion technique, you only have to implement the first one. To do so, you will have to create a structure similar to the one in Project 1 (you can re-use that one), a file for training a model (train.py), another one for evaluating it (evaluate.py) and another one for running the saliency map and savng the visualization (explain.py)
