# Extra 1

This is the first extra for the course. The value of it will be a 0.5 points increase over the final grade of the course. The deadline is the same as for the first project, but for this, no slip day will be allowed. 

## Description
For this extra, you will have to read and implement two explainability techniques for a Deep Learning model. The techniques are described in this [paper](https://arxiv.org/abs/1312.6034). You should read it, understand it (we will ask you some questions about it) and implement it (only the explainability techniques).

To do so, you will have to create a structure similar to the one in Project 1 but using the Cifar10 dataset. Then, you should add an explain file to run the explainability techniques and save the visualization in a pdf file.
