# Extra 3

This is the third extra for the course. The value of it will be a 0.5 points increase over the final grade of the course. The deadline is the same as for the fourth project, but for this, no slip day will be allowed. 

## Description

For this extra, you will have to read the following [paper](https://arxiv.org/abs/2010.11929) and implement a Vision Transformer ViT. To do that, you are not allowed to use the nn Attention layers, you should build your own implementation. Then, train and evaluate it with the imagenette dataset.

## Submission

It is expected a zip containing the src folder, which should have a similar structure to the one used in the projects, and a csv file with a table with the accuracies of the models (several hyperparameters that you have tried).
