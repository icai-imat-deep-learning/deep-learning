# Extra 2

This is the second extra for the course. The value of it will be a 0.5 points increase over the final grade of the course. The deadline is the same as for the second project, but for this, no slip day will be allowed. 

## Description

For this extra, you will have to read the following [paper](https://arxiv.org/abs/1505.05424) and implement a Linear and Convolutional Bayesian Neural Network, defining the weights as Gaussian distributions as it is done in the paper. You should compare these techniques with the torch versions using MNIST dataset for classification. You can use the torch.nn layers for Bayesian Neural Networks but you should ensure the weights are defined as explained before.

## Recommendation
Use shallow networks, since the Bayesian versions will be much easier to train.

## Submission

It is expected a zip containing the src folder, which should have a similar structure to the one used in the projects, and a csv file with a table with the accuracies of the models.
