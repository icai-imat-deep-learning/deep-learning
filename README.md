# Deep Learning Lab

This repository contains the code for all the projects and exams for of the Deep Learning Course of iMAT degree. The repository is divided in different sections. All the code here is expected to be placed in another repository, creating a template repository for github classroom, except old exams that will be uploaded as a zip.

## Projects

The projects/ folder contains the code for the projects during the course. In each project you will find two folder, the exercise and the solution. The solution has just the same structure of the exercise but it is solved with the proper code. It is just meant to help in solving doubts or in grading. There will be 4 projects with a value of 5% of the course mark. These exercises are also expected to be a proper training for the exams.

Regarding late policy, there won't be any reschedules of the submission dates, however each student has 3 late days which he may use as he considers. These 3 late days, will be days where the student can submit without any penalizing policies. 

## Extras

The extras/ folder contains the extras for the course. Each of the extras has a value of 0.5 points over the final mark of the course. The extras are much more difficult and open, but they offer a significant possibility of achieving a higher mark. Here the only provided thing will be the readme. We should create assignments in GitHub Classroom in a similar way than with projects.

## Exams

The exams folder contains the past exams, and the ones used for this year. Past exams should be uploaded as a zip to Moodle. Every exam has a similar structure than projects, with an exercise and a solution folders, and the same parts for each of these parts.

## Grader

The grader can be used to grade any GitHub Classroom project.
